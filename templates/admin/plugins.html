说明

插件是 plugins/<slug>/__init__.py 形式的一个 Python 包：

plugins/
└── html2md/
    ├── __init__.py   # 必含 TOOL 清单 + router
    ├── converter.py  # 任意辅助模块
    ├── templates/    # 可选：页面模板
    └── static/       # 可选：静态资源（/plugins/<slug>/static）

上传后点击「热重载插件」立即生效；加载失败会显示在下方列表中并附带错误原因。 内置示例：plugins/text-lines/（「文本行处理」）。
